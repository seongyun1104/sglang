# I0 result: physical KV-page aliasing on H100

Date: 2026-08-23

Overall result: `PARTIAL`

```text
physical page aliasing -> isolated FA3 latency reduction: supported
contiguous vs scattered duplicated placement: unresolved below 2% floor
HBM/L2 mechanism: unresolved because performance counters were unavailable
optimization or upstream feature PR: not authorized
```

The primary anchor contained all six A/B/C orders, three seeds, cold-ish and

## Anchor result

Warm aggregate medians:

| Layout | Median latency |
|---|---:|
| A: shared/aliased | 0.39144 ms |
| B: duplicated-contiguous | 0.45069 ms |
| C: duplicated-scattered | 0.45573 ms |

```text
A versus B speedup: 13.15%
B versus C scattering penalty: 1.11%
alias-supporting seed/order strata: 16/18
required support: 12/18
Gate A status: I0_ALIASING_CANDIDATE
```

Cold-ish aggregate medians were 0.31104, 0.40598, and 0.41202 ms for A, B,
and C respectively. `cold-ish` retains the contract's limited meaning: a 128 MiB
buffer was touched before the measured call, not a guaranteed hardware-cold cache.

## Alias-dose response

After the anchor passed, the same shape was measured at four shared-prefix
fractions. Each point used all six layout orders, three seeds, both cache states,
ten excluded warmups, and 30 repetitions. Each point produced 3,240 samples.

| Aliased prefix | A warm median | B warm median | A-vs-B speedup | Supporting strata |
|---:|---:|---:|---:|---:|
| 25% | 0.41616 ms | 0.44758 ms | 7.02% | 18/18 |
| 50% | 0.38411 ms | 0.44702 ms | 14.07% | 18/18 |
| 75% | 0.36315 ms | 0.44698 ms | 18.75% | 18/18 |
| 90% | 0.35230 ms | 0.44606 ms | 21.02% | 18/18 |

The B-versus-C penalty remained between 0.71% and 1.17%, below the preregistered
2% floor. The monotonic A-versus-B dose response, exact output equality, and full
18/18 support at every dose localize the latency effect to physical page reuse
rather than simple contiguous/scattered placement in this isolated reproducer.

This is a component-level causal result for the measured FA3 path. It is not a
whole-model Qwen3.8 speedup claim and does not imply that unique page count equals
HBM traffic.

## Launch geometry

An untimed Nsight Systems capture observed 39 FA3 calls. Every main FA3 call used
the same kernel specialization and launch geometry:

```text
kernel: FlashAttnFwdSm90, head dimension 256, dynamic persistent tile scheduler
grid: 132 x 1 x 1
block: 384 x 1 x 1
instances: 39
```

The combine and preparation kernels also had one common geometry per call. Thus
the A/B/C latency difference was not caused by selecting a different FA3 kernel
or launch shape.

## Mechanism boundary

Nsight Compute 2025.3.1 failed before metric enumeration with:

```text
ERR_NVGPUCTRPERM: permission denied for NVIDIA GPU performance counters
```

The container's root user also lacked permission to lock GPU clocks. Gate B HBM
traffic and Gate C L2 measurements were therefore not run. The result must remain
`PARTIAL`: physical aliasing is localized as the causal input, but the proposed
L2-hit/HBM-read mechanism is not yet measured.

## Next permitted action

Use an H100 environment that explicitly permits Nsight Compute performance
counters and clock control. Re-run only the isolated A/B anchor and collect:

```text
Gate B: DRAM read bytes/sectors and throughput
Gate C: L2 requested sectors, hit rate, misses, and throughput
```

Do not implement a scheduler, adaptive-K feature, cache-aware batching policy,
or production SGLang PR from this partial result.

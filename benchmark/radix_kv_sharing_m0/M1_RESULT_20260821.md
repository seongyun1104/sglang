The measured interaction, defined as shared efficiency divided by duplicated
efficiency minus one, was:

| K | Code completion | Structured JSON |
| ---: | ---: | ---: |
| 0 | +0.057% | +0.094% |
| 1 | -0.003% | +0.289% |

| 4 | -0.199% | -0.048% |

The largest absolute interaction was 0.628%, below the preregistered 2% minimum.
More importantly, the optimal K was identical between physical layouts in every
aggregate and seed-level comparison.

## Interpretation boundary

The allowed conclusion is:

> For the tested acceptance-bearing natural workloads, Radix physical page sharing
> does not provide useful additional state for fixed-K selection beyond the logical
> workload state. The optimal K is unchanged and the measured interaction is below
> 0.63%.

The result does not retract M0: long shared prefixes materially reduced isolated
target-verification time. It shows that this effect did not translate into a
physical-sharing × K interaction for the natural workloads that supplied meaningful
speculative acceptance.

The following work is not authorized by this result:

- adding a Radix physical-state axis to the adaptive speculative controller;
- modifying or expanding PR #31716 with this experiment;
- opening a Radix-aware speculative-depth feature PR;
- claiming that Radix sharing never affects optimal K under any workload or context.

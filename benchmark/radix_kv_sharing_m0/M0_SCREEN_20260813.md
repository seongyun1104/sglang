## Screen outcome

All 36 `(BS, context, K, seed)` rows passed the paired hard controls after excluding
only symmetric underfilled tail records caused by the same early EOS in both layouts.
Ten timing pairs and four footprint pairs were excluded and retained in the raw
artifacts as auditable counts. No asymmetric underfill occurred.

| BS | Logical context | Median shared page reuse | Duplicated reuse | Median paired verify-time difference |
|---:|---:|---:|---:|---:|
| 8 | 8192 | 78.63% | 0% | shared 13.74% faster |
| 8 | 16384 | 78.70% | 0% | shared 21.97% faster |
| 16 | 8192 | 84.26% | 0% | shared 21.58% faster |
| 16 | 16384 | 84.32% | 0% | shared 29.37% faster |

Every one of the 12 `(BS, context, K)` aggregate cells had three valid seeds, the
same direction, and an absolute median effect greater than the preregistered 2%
screening floor.

## Important boundary

The effect size was nearly unchanged across `K=0,2,4` within a fixed BS/context
condition. This supports only the M0 mechanism:

> Physical KV sharing changes the target-path CUDA time at fixed logical workload.

It does not yet show that physical KV state changes the optimal speculative depth.

The generated shared-prefix workload also produced zero correct draft tokens per
request in the retained records (`acc_length=1.00`). Therefore this workload cannot
answer M1's optimal-K question. It is valid for the fixed-K M0 cost test, but M1 must
use an acceptance-bearing, semantically coherent workload while preserving paired
prompt and acceptance controls.
